Перетащите сюда папку с презентацией или сайтом

Файлы остаются в вашем браузере и в интернет не уходят. Chrome при выборе папки спросит, загрузить ли файлы на сайт: это его обычный вопрос. Без вопроса можно просто перетащить папку

  1. 1

    Откройте

    Страница откроется здесь же, уже в режиме правок

  2. 2

    Правьте

    Тяните блоки мышью, текст правится двойным щелчком, Alt + щелчок оставляет замечание

  3. 3

    Сохраните

    Скачать отдаст готовый файл с вашими правками, ИИ не нужен

    Если есть замечания словами или правка сложная, Отдать ИИ соберёт всё в одно сообщение для чата. Ответ ИИ вставьте кнопкой Вставить ответ ИИ

Для Claude Code, Codex, Cursor, GigaCode. Отправьте фразу агенту из папки с презентацией

Включи режим правок для этой папки. Возьми его с github.com/Tomb-Raider/rezhim-pravok и сделай всё по его «Инструкции для ИИ». Правки, которые я потом пришлю, вноси по ней же
  1. 1

    Отправьте фразу

    Агент скачает режим правок и откроет страницу в браузере. Нужен Python 3

  2. 2

    Правьте

    Так же, как онлайн: тяните, правьте текст, оставляйте замечания

  3. 3

    Отдайте правки агенту

    «Скопировать правки» и вставьте в чат с агентом. Он сам внесёт их в файлы

Перетащите кнопку на панель закладок

Режим правок

Закладка включает режим правок прямо на открытом сайте, даже если его файлов у вас нет. Сайт не меняется, правки видите только вы

  1. 1

    Добавьте закладку

    Перетащите кнопку «Режим правок» на панель закладок. Если панели не видно, Cmd + Shift + B на Mac или Ctrl + Shift + B на Windows

  2. 2

    Откройте сайт и нажмите закладку

    Внизу появится панель режима правок

  3. 3

    Отдайте правки

    «Скопировать правки» соберёт всё одним текстом. Отправьте его тому, кто делает сайт, или ИИ вместе с файлами сайта

Некоторые большие сайты своей защитой не пускают закладку
